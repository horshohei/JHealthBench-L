## 確定した内容

1. **既存の記録を一次の材料にする（案A）**
   - 第1医師がケースごとに選んだ修正方針コード（14コード、79件中54件）。
   - LLM案の基準ごとの種類（translate／edit／adapt）、第1医師の採用元と修正理由、後続レビューの要修正65項目、メタレビューの削除18・追加10・配点変更14。
2. **異なる2つのLLMで基準ごとに分類する（案B）**
   - 対象：T と L で本文が違う基準771、会話の変更53ターン、削除・追加・配点変更。
   - 分類：14コード＋J（言語のみ）＋G（一般的な改善）＋NONE。医師がそのケースで選んだコードを優先候補として示し、外のコードも許す。
   - ラボの2モデルで各2回。主採点役とは別のモデルを優先する（主採点役が Qwen3.8-27B なら、分類役は gpt-oss-120b と DeepSeek V4 Flash など）。
   - 報告：2モデル間の κ（コード別）、2回の安定性、医師のケース単位コードとの整合。
3. **著者1〜2名が層別無作為抽出の150単位を確認する（案C）**
   - 層は分類コード×変更の出所（LLM案・人手修正・メタレビュー）。抽出の seed は事前に固定する。
   - 目安は1名あたり3〜5時間（1単位1〜2分）。2名で行う場合は同じ150単位を独立に見て、著者間の一致も出す。
   - 著者は研究チーム内であり独立した評価者ではない点を Limitations に書く。
